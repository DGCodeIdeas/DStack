# Getting Started

This guide walks you through setting up DStack Panel locally on Linux (Ubuntu/Debian/Kubuntu). It covers prerequisites, dependency installation, environment configuration, and first-time startup.

---

## Prerequisites

| Tool | Minimum Version | Install Command (Ubuntu/Debian) |
|------|-----------------|---------------------------------|
| PHP | 8.2 | `sudo apt install php8.2 php8.2-cli php8.2-mbstring php8.2-xml php8.2-curl php8.2-sqlite3` |
| Composer | 2.x | `php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');" && php composer-setup.php --install-dir=/usr/local/bin --filename=composer` |
| Node.js | 18+ | `sudo apt install nodejs` or use `nvm` |
| Bun | 1.x | `curl -fsSL https://bun.sh/install \| bash` |
| Git | 2.30+ | `sudo apt install git` |
| Docker Engine | 24.0+ | `sudo apt install docker.io` |
| Docker Compose | v2 | `sudo apt install docker-compose-plugin` |

### Verify Prerequisites

```bash
php -v
composer --version
node -v
bun -v
git --version
docker --version
docker compose version
```

All commands should output version information without errors.

## Installation Steps

### 1. Clone the Repository

```bash
git clone https://github.com/DGCodeIdeas/DStack.git
cd DStack
```

### 2. Install PHP Dependencies

```bash
composer install --no-dev --optimize-autoloader
```

For local development with testing tools:

```bash
composer install
```

### 3. Install Node Dependencies

```bash
bun install --frozen-lockfile
```

### 4. Configure Environment

```bash
cp .env.example .env
```

Edit `.env` and set the following values:

| Variable | Description | Default |
|----------|-------------|---------|
| `APP_NAME` | Application name | `DStack Panel` |
| `APP_ENV` | Environment | `local` |
| `APP_KEY` | Generated by `php artisan key:generate` | — |
| `APP_DEBUG` | Show debug info | `true` (local) |
| `APP_URL` | Base URL | `http://localhost` |
| `DB_CONNECTION` | Database driver | `sqlite` |
| `DB_DATABASE` | SQLite file path | `database/panel.db` |
| `DSTACK_ROOT` | Root path for DStack services | `/opt/dstack-panel` |
| `DSTACK_DOCKER_COMPOSE_FILE` | Docker Compose file | `${DSTACK_ROOT}/docker/docker-compose.yml` |
| `PROJECTS_ROOT` | Projects directory | `/home/dgi/devstack-manager/projects` |

### 5. Generate Application Key

```bash
php artisan key:generate
```

### 6. Run Database Migrations

```bash
php artisan migrate --force
```

### 7. Build Frontend Assets

```bash
# Development (with watch)
bun run dev

# Production
bun run prod
```

### 8. Start the Panel

#### Option A: Development Server (single instance)

```bash
php artisan serve --host=0.0.0.0 --port=5000
```

The panel will be available at `http://localhost:5000`.

#### Option B: Blue-Green systemd Instances (production-like)

```bash
# Create instance env files
cp .env .env.green
cp .env .env.blue

# Edit ports (green=5000, blue=5001) and any other instance-specific values
sudo nano .env.green
sudo nano .env.blue

# Install systemd template
sudo cp systemd/dstack-panel@.service /etc/systemd/system/
sudo systemctl daemon-reload

# Start both instances
sudo systemctl enable --now dstack-panel@green
sudo systemctl enable --now dstack-panel@blue
```

### 9. Verify Installation

```bash
# Check routes
php artisan route:list

# Run tests
php artisan test --compact

# Health check
curl -s http://localhost:5000/up
curl -s http://localhost:5000/api/health
```

## Project Structure

```
DStack/
├── app/
│   ├── Console/Commands/      # Artisan commands (dstack:update, dstack:version-sync)
│   ├── Http/
│   │   ├── Controllers/       # API and panel controllers
│   │   └── Requests/          # Form request validation
│   ├── Models/                # Eloquent models
│   └── Services/              # Business logic (Docker, SSL, Backup, etc.)
├── bootstrap/app.php          # Laravel 12 application bootstrap
├── config/                    # Configuration files (dstack.php, auth.php, etc.)
├── database/
│   ├── migrations/            # Database schema migrations
│   └── seeders/               # Database seeders
├── docker/                    # Docker Compose, nginx configs
├── nginx/                     # Host nginx vhost templates
├── old/                       # Legacy Flask code (archived)
├── public/                    # Web root (assets, index.php)
├── resources/
│   ├── css/                   # Stylesheets
│   ├── js/app.js              # Panel frontend (SPA with SSE)
│   └── views/                 # Blade templates
├── routes/
│   ├── web.php                # Web routes (panel SPA fallback)
│   ├── api.php                # API routes
│   └── console.php            # Artisan command definitions
├── storage/                   # Logs, cache, SQLite database
├── systemd/                   # Blue-green systemd templates
└── tests/                     # PHPUnit tests
```

## Development Workflow

### Running Tests

```bash
# All tests
php artisan test --compact

# Specific test file
php artisan test tests/Feature/ServiceControllerTest.php

# Specific test method
php artisan test --filter=test_it_lists_services
```

### Code Style

This project uses Laravel Pint for code styling:

```bash
vendor/bin/pint --format agent
```

### Frontend Development

```bash
# Watch mode (recompiles on change)
bun run dev

# Production build
bun run prod
```

### Database Seeds

```bash
php artisan db:seed
```
